# 视觉规范：档案纸拼贴（MG-VOXSTAGE）

> 风格板：`assets/mg-voxstage-style-board.png`。开工前先看它——这份文档是它的实现说明，
> 不是另一套风格。所有新片、新组件、新素材都必须服从这里的五支颜色和三条材质规则。

一句话：**每一帧都该像"从旧报纸/旧地图上剪下来、贴在牛皮纸上、用红笔圈过"的一页**。
不是纸艺 UI，不是扁平卡片，更不是带投影的幻灯片。

---

## 1. 五支颜色（`src/theme.ts`）

| 色 | 值 | 用途 |
|---|---|---|
| 存档米棕 | `#D3C2A4` / 深 `#BFA984` | 底纸。**不允许纯色填充**，见第 2 节 |
| 纸片米白 | `#F8F1E0` | 卡片、字幕条、纸片。不用纯白 |
| 油墨纯黑 | `#1A1A1A` | 标题、正文、地图线、描边 |
| 半调网点灰 | `#8C8C8C` | 次要信息、第三支强调 |
| 醒目正红 | `#D62E1F` | **只做强调**：划线、描边、箭头、色条、偏移剪影 |
| 芥末黄 | `#D9A441` | 次级强调，用量比红少一半 |

规则：

- **红不铺面。** 红是记号笔，不是背景色。整片红色面积超过 10% 就说明强调用滥了。
- **没有蓝/青/品红。** 它们属于扁平 UI，不属于印刷品。`ACCENT_CYCLE` 只在
  `[红, 黄, 红, 灰, 红]` 里轮转。
- **深色底只给 `quote`。** 开场不再压黑——深底会打断"同一张纸"的连续感。
  夜底是暖墨黑 `#1C1915`，不是冷灰黑。

## 2. 底纸：三层材质，缺一不可

`PaperStage` 从下到上：

1. **做旧色层**：多层 radial-gradient 拉出不均匀的米棕 + 5 处固定的"霉斑"水渍。
2. **旧地图纹**（`MapTexture.tsx`）：街区、双线干道、等高线、河流、比例尺、指北针。
   整体旋转 -6.5°、缩放 1.16，避免读成表格。不透明度 0.52。
   地图自己再漂 12px、转 0.2°——它和底纸不是同一层，视差让"镜头在纸上慢慢扫过"成立。
3. **半调网点 + 纸纤维 + 账册格线**：5-17px 周期的点阵。网点以 5px/秒缓慢爬移，
   像印张在机器上走了一点点：全画幅的高频边缘一直在变，静态拍也不会被压成一张图。
   幅度必须保持在像素级、低频，再大就变成"画面在抖"。

再叠两层动态：

- 整幅 `sway` 漂移（6px / 240 帧）+ 曝光呼吸（±2 灰阶）。
- 空气里的纸屑尘埃（34 粒，独立上浮）。

三条材质禁令：

- **禁止纯色背景。** 平涂在帧间完全一致，压缩器会把几十帧压成一帧，回放起来"死"。
- **禁止 `feTurbulence` / SVG 滤镜做纹理。** 逐帧重算全画幅噪声，渲染慢好几倍。
  用 CSS 渐变 / 静态 SVG 几何。
- **禁止给整幅加 `mix-blend-mode`。** 祖先有 `transform` 时会出合成残影。

## 3. 组件语法：剪、贴、写

| 手法 | 实现 | 用在哪 |
|---|---|---|
| 毛边 | `roughEdge(seed, amp=2.4~4.2)` | 纸片、字幕条、胶带 |
| 纸片投影 | `PaperSheet` 的三层 `drop-shadow` | 所有卡片 |
| 胶带 | `Tape` | 卡片顶端、照片角 |
| 印刷网点 | `sheetTexture`（3% 脏） | 每张纸片、字幕条 |
| 红笔划线 | `BrushUnderline`（裁剪揭示） | 强调词、对比栏标题 |
| 半调 + 红偏移剪影 | `ShapeMark`（CompareSplit / NoteLayer） | 几何对比、论点图形 |
| 手绘批注 | `visual.annotations`（`NoteLayer`） | 圈数字、指方向、量宽度、压印章 |
| 印刷化素材 | `cutouts[].print: true` | 写实渲染的抠图元素 |

**不要出现的东西**：圆角面板、实线分栏、彩色描边按钮、整块纯色色块、
带玻璃/发光/渐变高光的 3D 元素、任何"页面编号 / 进度百分比"式 UI 文案。

## 4. 字体与排版

- `FONT_DISPLAY` = 思源黑体 900（中文），`FONT_NUMERAL` = Archivo Black（纯数字）。
- 标题一律**粗、紧、左对齐或贴边**；正文 700，行高 1.45-1.5。
- 强调 = **墨色字 + 红笔划线**（+ 1.16× 字号），不是彩色字。
  彩色字在米棕底上对比不足，而且会把红色稀释成装饰。
- 保留三条固定分区：左上 `pad,64` 报头（片名，**无页码**）、
  左下 `pad,96` 出处、底边 4px 章节线。内容上了底部字幕带（≈858px）就会被盖住。

## 5. 运动

风格板的四格分镜就是全片的运动清单：

| 动作 | 参数 | 位置 |
|---|---|---|
| 弹性弹入 | spring，阻尼 11-12，0.5s | 所有卡片/元素入场 |
| 数字跳动 | 0 → 目标，easeOutCubic，0.9s，卡在旁白念到数字 | `StatCard` / `Odometer` |
| 红笔划线 | 8 帧从左划到右 | `BrushUnderline` |
| 批注画入 | 12-14 帧沿路径长出去 | `NoteLayer`（`annotations`） |
| 横向缓移 | 2%-3% 画幅，全程匀速 | `camera: "pan"` / `ambient` |
| 底纹漂移 | 地图 12px/160 帧、网点 5px/秒 | `PaperStage` |

另外必须常开：整幅缓慢推近（`push_in` 默认 3.5%）、元素级 `floatAt` 呼吸（3-5px）、
纸屑尘埃。**一拍里不能有超过 1.5 秒完全静止**——`check_motion.py` 会把它标成死拍。
