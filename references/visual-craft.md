# 画面变化：每拍写四件事，每 2–3 秒出一个看得见的新东西

> 这份管"变化够不够"，`readability.md` 管"看不看得清"，`arcs.md` 管"拍子怎么排"。
> 写稿时照第一节给每拍写变化清单，挑转场查第三节，选组件查第五节；
> 出片后用 `check_richness.py` 量，别凭感觉说"够活泼了"。

## 一、每个镜头写清四件事

| 环节 | 是什么 | 时长 / 幅度 | 落到哪个字段 |
|---|---|---|---|
| 进场 | 怎么来：弹出、掉落、滑入、描出、拍上 | 0.2–0.5s，比关键词早 0.03–0.1s | `motion`；标题纸片落用组件里的 `PaperDrop` |
| 主动作 | 这一拍要讲的那件事怎么演：数字滚动、右栏进场、导轨生长、盖章、划线 | 跟着口播，卡在关键词上 | 组件内部（`useBeatWords`）；`impact` 给重量 |
| 次要动作 | 一直动的小东西：呼吸、飘动、粒子、光标、慢推 | 全程；位移 2–6px、缩放 1–3%、周期 1.5–4s | `ambient`、`vfx`、`camera`、`layers`、`floatAt` |
| 出场 | 怎么换到下一拍：盖章后切、撕走、推走、盖屏 | 0.3–0.7s，卡句界 | 下一拍的 `transition` + `transitionFrames` |

写进 `script.json` 的 `change` 对象（**可选**，写了 `preflight.py` 就要求四项齐全）：

```jsonc
{
  "id": "tumu",
  "narration": "……",
  "transition": "paperCover",
  "transitionFrames": 18,
  "change": {
    "enter": "标题纸片从上方落下，落定回正",
    "main": "念到「土木堡」时红章砸下，数字从 20 万跳到 50 万",
    "secondary": "底纸网点缓慢爬移，左上角小人眨眼",
    "exit": "纸片盖屏，切到下一拍"
  },
  "visual": { "kind": "stat", "value": 500000, "unit": "人", "label": "土木堡之变" }
}
```

- 也认中文键名：`进场 / 主动作 / 次要动作 / 出场`。两种混写会报重复。
- **主动作写不出来，就说明这一拍只是把字摆好了**——重想画面，不要把字段留空。
- `visual.elementMotion` 仍可用，是给实现看的一句话摘要；`change` 是四段拆开，
  写稿阶段用它逼自己想清楚"这一拍到底在演什么"。
- 次要动作一屏最多 2 种，幅度小、离正在讲的东西远一点，别抢主动作。

## 二、多久要有一次看得见的新变化

“看得见”指缩到手机上也看得出：小于 10% 画面面积的变化（一个小图标闪一下）
只算次要动作，不算新变化。

| 多久 | 要什么 | 依据 |
|---|---|---|
| 每 2–3 秒 | 新东西进场 / 变形 / 换色 / 挪位 / 推近拉开 | 影视飓风 6 期口播镜头中位数 2.8–3.4s |
| 每 3–5 秒 | 一次大变化：换镜头、换板、换版面 | 平均每镜 3.1–4.5s |
| 一直 | 至少一样东西在动；静止不超过 2 秒 | 盲测：被判"更丰富"的版本最长静止 0.6–1.4s |
| 开头 3 秒 | 最密：1–1.5 秒一个变化 | 达芬奇那期第 1 分钟切 44 次 |
| 讲原理 | 一张图可以撑 10–20 秒，但每 2–3 秒亮起新的一步 | 频闪那期一张动效图撑 34 秒，滑块一直在走 |

讲完停住的那几秒最容易"死"：给主体一个呼吸（缩放 1±1%，周期 2–3s）或慢推；
上一拍的主角能留就留，缩小挪到角上陪下一拍，比清空重来多一次变化。

## 三、转场换着用

- 全片至少 3 种转场；同一种别连着用 3 次；换话题用大转场（盖屏、翻页、擦除），
  段内换镜头用小转场（推、叠化、硬切 + 一下冲击）。
- 硬切连续用是允许的（同类内容比淡入淡出利落），`check_rhythm.py` 不会报；
  连续同一种软转场会报"等于没转"。
- 转场要像这套材料会发生的事：纸会掉、会撕、会翻。纸艺常用
  `paperCover` / `paper` / `bookFlip` / `slide` / `wipe`，完整清单与用法见
  `components.md#转场`。

## 四、怎么量

渲染之后跑：

```bash
python scripts/check_richness.py --project . --video out/video.mp4
```

- 每 2.5 秒抽一格（裁掉底部字幕带），算相邻格的平均像素差；**<4 读作"几乎没变"**。
- 判定：相邻格平均 **≥10** 且**没有**"几乎没变"的对。
- 另报"在动的帧"（和 0.1 秒前比差 >0.3）和"最长静止"；静止 >2 秒给提醒。
- 输出 `out/richness/richness.txt` + `sheet.png`（没有 Pillow / 完整 ffmpeg 时给 HTML）。
  看联络表标"几乎没变"的格，补一个新东西进场、推近或换色。
- 实测锚点：`ming-ep01`（纸艺 64.6s）相邻格平均 35.1、0/25 几乎没变、最长静止 0.7s；
  `demo-film` 5/15 对几乎没变、最长静止 5.9s——后者就是要返工的样子。
- "在动的帧"不是 KPI：整幅抖动也能把它拉满。先保证每 2–3 秒有看得见的新东西，
  再谈一直在动的小东西。

## 五、抽象概念 → 现有画面

先归类，再找**看得见、会动**的东西演它；关键动作卡在说这个词的那一刻（`useBeatWords`）。
下表只列本 skill **已经有的** 16 种视觉和叠加层；"缺口"一列是真没有对应组件，
先用叠加层拼，仍不够再按 `components.md#加一个新组件四个文件缺一不可` 加。

| 概念（口播怎么说） | 首选 kind / 层 | 让它动起来 | 缺口 / 备注 |
|---|---|---|---|
| 关键词、金句、结论 | `kinetic` / `highlight` / `quote` | 逐词弹出、纸片强调词拍上、马克笔从左划过 | — |
| 定义、誓言、承诺、"写下这句话" | `handwrite` | 笔尖走过字才出现，强调词换红笔；写完抬笔退出 | 一拍一句短话，单行 ≤12 字；只适合全片 1-2 次，用多了像板书写真 |
| 一个数有多大 | `stat` / `odometer` | 数字从 0 滚到目标；odometer 逐位步进 | 旁白要把数字放在句子前段 |
| 增长、变多、规模 | `chart`（bar/line）/ `stat` | 柱子一根根长高、折线画出来、数字滚动 | — |
| 对比、前后、取舍 | `compare` / `split` | 右栏等旁白念到才进场；中间放 `mark` 图形 | 两栏都只有字时一定给 `mark` |
| 并列原因、清单、分类 | `cards` / `split` / `chart` donut | 卡片一张张落下、面板依次亮、环段画出来 | 4 格以内用 `split`，再多会挤 |
| 累积、负担、越堆越多 | `stack` | 条目从下往上垒，越垒越高 | 需要"歪倒"用 `pieces`/`cutouts` 做 |
| 步骤、流程、因果 | `timeline` / `route` / `split` | 导轨一截截生长、节点依次点亮、路径描出来 | **没有通用流程图/箭头组件**；3 步以内用 timeline，超过就自定义 |
| 时间、演变、历史 | `timeline` | 节点跟着旁白依次点亮，导轨往前爬 | 最多 5 个节点 |
| 地点、迁移、势力范围 | `route` | 连线用 dashoffset 画出来、节点依次亮 | 底图坐标是画布百分比 |
| 具体实物、场景、证据 | `image` / `callout` | Ken Burns 推近、圈注画出、箭头延伸 | 每片必须配图（≥max(3, ceil(拍数/3)) 拍） |
| 人物、角色、身份 | `person` | 肖像入场带重冲击，姓名/身份/台词依次揭示 | `quote` 只写真实台词 |
| 组成、占比、部分与整体 | `chart` donut / `split` | 环段依次画出、面板逐格出现 | 环形图不会自动合并长尾，先自己合并 |
| 范围、窗口、容量、上限 | `annotations`（measure/circle）压在 `kinetic`/`image` 上 | 框/括号随关键词画出，内容进出框 | **没有通用"容器/取景框"组件**；要缩放取景框就自定义 |
| 输入 → 处理 → 输出 | `route`（3 点）/ `timeline` | 东西进站、出站变样，节点依次亮 | **没有机器/漏斗/管道组件**；真需要就自定义 |
| 缺失、遗忘、过时 | `pieces` 留缺口 / `cutouts` 飞出画面 / `annotations` 盖章 | 一块不飞回来、元素掉出框、红章砸下 | `cutouts` 有 `fall`（念到词就坠落）和静态 `opacity`；**没有现成的渐隐时间轴**，真需要淡出就在组件里写 |
| "不是 A，而是 B" | `highlight` / `compare` | A 划掉、B 圈住；左右两栏错开进场 | `marks`/`circled` 必须是 `text` 里的原词 |
| 引用、证言、别人的话 | `quote` | 深色底明暗跳变，按强调词分段进场 | `attribution` 只写真实来源 |

叠加层（任何 kind 都能挂）：`layers` 分层背景做视差、`pieces` 切图飞入拼回、
`cutouts` 独立抠图元素互相遮挡、`annotations` 箭头/圈/量尺/标签/章、
`stage3d` 真 Z 轴遮挡、`vfx` 纸屑/冲击放射。先用它们，别再堆新组件。

## 六、自查

**写分镜时**
- [ ] 每拍 `change` 四件事都写了；主动作写不出来的重想
- [ ] 相邻拍不是同一个版式只换字
- [ ] 转场至少 3 种，没有连着 3 次同一种
- [ ] 开头 3 秒至少 2 个变化

**出静帧时**（`stills.py --scale 480`）
- [ ] 至少两层：背景有纹理/远景/光斑，不是纯色底上摆字
- [ ] 主体之外有次要动作的东西在场，但没抢戏
- [ ] 这一帧有正在发生的动作（写到一半、正在掉、正在通电），不是全摆好等着
- [ ] 三张之间版面、主体大小和位置明显不一样

**出整段后**
- [ ] `check_richness.py` 判"过"：平均 ≥10、0 对"几乎没变"
- [ ] 没有静止超过 2 秒的段
- [ ] 联络表里每格都看得出新东西；标"几乎没变"的格补变化
- [ ] `check_motion.py` 没有死拍、九宫格显示元素级动画

## 出处

1. 影视飓风 6 期视频的镜头切换统计（ffmpeg 场景检测 + 每 3 秒抽帧），原始数据不随 skill 发。
2. 2026-10-09 盲测 6 版（剪纸 / 粉笔 / 霓虹 × 用/不用 skill）：相邻格平均、在动帧占比、
   最长静止由 `丰富度检查.mjs` 当场算；作者盲选"更丰富"的版本与相邻格平均一致。
3. dashi-animationstyle 的 `knowledge/动效和画面变化.md`（v1.2）与本 skill 的
   `ming-ep01` / `demo-film` 实测；阈值在纸艺片上复核过，见 `tuning.md`。
