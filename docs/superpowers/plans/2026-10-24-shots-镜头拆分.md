# shots 镜头拆分架构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把一个 beat 拆成多个 1.5–2.5s 的镜头（shot），镜头边界锚在词级时间戳上，shot 间默认硬切——用"切"代替"漂"，消掉一个 beat 一个画面的 PPT 感。

**Architecture:** `shots` 挂在 `visual.shots` 里（vox_tts.py 对 visual 整块透传，管线零改动）；运行时纯函数 `computeShots` 从词级时间戳派生镜头边界（从句拆分 + 短句合并，或显式 shots 覆盖）；渲染层在 beat 内为每个 shot 建嵌套 `<Sequence>`，复用 A+B 的 `useEntrance`/`useBeatPresence` 配方机制；纸台/运镜/特效留 beat 级，只有内容层切镜头。配方按**全局 shot 序号**轮换，跨拍相邻镜头也保证不同。

**Tech Stack:** Remotion 4.0.535 / React 19 / TS 5.6.3；拆分逻辑是纯 TS（无 React 依赖），用 Node 24 原生跑 + esbuild bundle 做测试；Python 校验脚本保持零第三方依赖。

**Spec:** 无独立 spec 文档——设计在本会话定稿，本计划的 §Design 即 spec。

**基线（重要）:** 本计划基于工作区里 **A+B（motion/layout）已实现但未提交**的 16 个文件之上。执行前先把 A+B 单独提交，C 的每任务提交不得卷进 A+B 的改动（Task 1 改的文件与 A+B 高度重叠）。

## Design

### 数据模型（写进 `assets/template/src/timeline.ts`）

```ts
export type ShotTransition = "cut" | "crossfade";

/** 一个镜头。时间单位是秒，相对本拍开头；运行时 ×fps 转帧。 */
export type ShotSpec = {
  from?: number;         // 省略 = 接上一镜结尾（首镜 = 0）
  to?: number;           // 省略 = 下一镜开头（末镜 = 拍尾）
  words?: string[];      // 本镜头单独上屏的词（kinetic）；省略 = 该窗口内的旁白从句
  motion?: MotionRecipe; // 省略 = 按全局 shot 序号轮换
  layout?: LayoutMode;   // 省略 = 继承拍级 layout
  transition?: ShotTransition; // 本镜头怎么进，默认 "cut"
};
```

`VisualSpec` 加 `shots?: ShotSpec[]`。**不放在 beat 级**：vox_tts.py 只有 `visual` 是整块透传的，放 beat 级要改管线。

### 运行时拆分（新文件 `assets/template/src/shots.ts`，纯 TS 无 React）

```ts
export const MIN_SHOT_SECONDS = 1.5;   // 镜头时长下限（45 帧 @30fps）
export const SHOT_FADE = 8;            // crossfade 交叠帧数
export const SHOT_PUNCT = /(?<=[，。！？；、,.!?;])/;  // 与 KineticText 的断句正则一致

export type Shot = {
  from: number;                 // 相对 beat 起点，帧
  durationInFrames: number;
  words: WordTiming[];          // 该窗口的词，t 已归零到 shot 起点
  narration: string;            // shot 内旁白（words 文本拼接，供 KineticText 断句兜底）
  shown?: string[];             // 上屏词覆盖（shotSpec.words 或拍级 visual.words）
  motion: MotionRecipe;         // 已解析
  layout?: LayoutMode;
  transition: ShotTransition;
};

export const computeShots = (beat: Beat, firstShotIndex: number, fps: number): Shot[];
```

拆分规则（定死）：

1. **非 kinetic kind** → 返回单镜头（v1 shots 只对 kinetic 生效；preflight 会挡掉其他 kind 写 shots，运行时兜底防呆）。
2. **`beat.words` 为空**（无声拍 / TTS 没出词边界）→ 单镜头兜底，不崩。
3. **`visual.shots` 存在（显式路径）**：条目按 from 升序排；from/to 缺省按"接上一镜 / 下一镜开头"补（全缺 = 均分拍长）；帧换算 `round(秒 × fps)` 后 clamp 进 `[0, beat.durationInFrames]`；`to ≤ from` 或越界的条目 clamp 到至少 1 帧。词窗口 = `beat.words` 里 `t ∈ [from, to)` 的切片，t 减 shot.from 归零；`narration` = 切片文本拼接；`shown` = shotSpec.words（没写 = undefined）。
4. **自动路径**（无显式 shots）：按 `SHOT_PUNCT` 在词流上切从句（以词尾带标点为准），每句一个镜头；句长 < `MIN_SHOT_SECONDS × fps` 的并进下一句（连续合并）；末镜头填到拍尾；合并后只剩 1 句 = 单镜头（≤3s 的拍自然就是单镜头）。`shown` = 拍级 `visual.words`（单镜头时）或 undefined（多镜头时——beat 级 words 在 shots 下失效，见 Review Focus 7）；`narration` = 本句词文本拼接。
5. **配方轮换**：`shot.motion = autoMotion(firstShotIndex + i, canBuildVisual(beat.visual))`。`firstShotIndex` 是**全局** shot 序号（VoxVideo 里累加游标），相邻 shot（含跨拍边界、含首尾 wrap）永不重复；单镜头拍退化为 `autoMotion(beatIndex)`，与 A+B 行为逐帧一致。
6. `layout` = `shotSpec.layout ?? beat.visual.layout`；`transition` = shotSpec 值（显式路径）或 `"cut"`（自动路径）。

### 渲染（`visuals.tsx` + 新文件 `src/ShotLayer.tsx` + `VoxVideo.tsx`）

- **VoxVideo.tsx**：`useMemo` 里跑 `BEATS.map((b, i) => computeShots(b, cursor, fps))`，累加 `cursor += shots.length`，把 `shots: Shot[]` 作为新 prop 传给 `BeatVisual`（全局序号由这里保证）。
- **visuals.tsx**：删掉 beat 级 `motion`/`entrance`/`EntranceContext` 内容块，换成：
  ```tsx
  {shots.map((s, i) => (
    <Sequence key={i} from={s.from}
      durationInFrames={s.durationInFrames + (shots[i+1]?.transition === "crossfade" ? SHOT_FADE : 0)}
      name={`${beat.id}/s${i}`}>
      <ShotLayer shot={s} beat={beat} accent={accent} tone={tone}
        ambientTransform={ambient} holdExit={i < shots.length - 1}
        fadeIn={s.transition === "crossfade" ? SHOT_FADE : 0} />
    </Sequence>
  ))}
  ```
  `ambient`（beat 级帧正确的常驻运动字符串）提前算好传下去；PaperStage / camera 层 / Starburst / Flash / sweep / AmbientLight / 角标全部留在 beat 级不动。crossfade 的实现：前镜 Sequence 向后多挂 `SHOT_FADE` 帧、后镜前 `SHOT_FADE` 帧 opacity 0→1——两个 Sequence 自然交叠，不引 TransitionSeries（shot 级转场绝不能进"视觉时钟"，音频时钟是 beat 级的）。
- **ShotLayer.tsx**（内部组件，不进 barrel）：props 如上。内部：`useCurrentFrame()`（shot 相对帧）、`useImpact((shot.words[0]?.t ?? 0) - 3, beat.visual.impact ?? "soft")`（冲击落在**本镜头**第一个词上——词级锚点的核心）、`useEntrance(shot.motion)`；`shotVisual = {...beat.visual, words: shot.shown, layout: shot.layout ?? beat.visual.layout}`；`shotBeat = {...beat, from: shot.from, durationInFrames: shot.durationInFrames, narration: shot.narration, words: shot.words}`；`contentTransform = [ambientTransform, beat.visual.impact ? impact.transform : ""].join(" ")`；`fadeIn > 0` 时内容层 opacity `interpolate(frame, [0, fadeIn], [0, 1], clamp)`。结构 = 现 visuals.tsx 158–181 行的入场层搬进来，Provider value 加 `holdExit`。
- **BeatPresence.tsx**：`EntranceContext` 类型改为 `{ recipe: MotionRecipe | null; holdExit?: boolean }`（默认 `{recipe: null, holdExit: false}`）；`useBeatPresence` 里 `holdExit` 为真时 `outP = 0`——**非末镜头不淡出**（镜头的"出"是硬切，只有整拍最后一个镜头负责拍级退场）。

### 校验（`preflight.py` / `check_rhythm.py`）

- **preflight**：`SHOT_TRANSITIONS = {"cut", "crossfade"}`；新 `check_shots(where, visual, motions, layouts, rep)`，在 `check_visual` 尾部调用。检查：shots 是数组；kind 必须是 kinetic（否则 err"shots 目前只对 kinetic 生效"）；每条是 dict；`from`/`to` 是 ≥0 的数字、都给时 `to > from`、按序且不重叠（`shots[i].to ≤ shots[i+1].from`）；`motion`/`layout`/`transition` 枚举合法；`words` 是字符串数组。warn：只有 1 条 shots（拆了等于没拆）。
- **check_rhythm**：新 `check_shot_rhythm(beats)`：把**显式 shots** 的拍平铺成镜头级配方序列（`shots[i].motion ?? ORDER[(全局游标) % 5]`，build 落在不可 build kind 顶成 drift，全局游标跨拍累加；无 shots 的拍整体算一个镜头），检查相邻镜头配方重复 → FAIL。自动拆分的拍在平铺里只算一个镜头（时长未知，合并结果脚本算不准——运行时全局序号已保证不重复，输出里注明）。`effective_motion` 对带 shots 的拍取**首镜头**配方，供拍级相邻检查继续工作。
- **selftest** 新增断言（先写后实现）：shot 枚举与声明一致、recipes.ts 是 ORDER 唯一真相（`_template_order()` 改读 recipes.ts）、computeShots 签名齐全、visuals.tsx 接线存在、BeatPresence 含 holdExit、preflight 对坏 shots 报错（kind 非 kinetic / to≤from / 重叠 / 坏枚举，直调函数断言）、check_shot_rhythm 检出跨拍相邻重复、node 子套件。

### 范围（v1 边界，写进文档）

- shots 只对 **kinetic** 生效。items 类（cards/stack/timeline/route/callout）的词级时间戳不在词流里，需要按项锚点的另一套机制，v1 不做（preflight 报错挡掉）。
- **shot 级 camera 不做**：camera 是 beat 级"整幅怎么动"的轴，shot 级再叠一层 transform 会复现 SKILL.md 记录的缩放叠加切字事故。shot 的节奏来自"切"。
- shot 间转场只支持 `cut` / `crossfade`，默认 cut。

断言清单（每条一个 `node:assert`）：
1. **空 words**：`words: []` 的 kinetic beat → 恰 1 个 shot，覆盖 `[0, durationInFrames]`，words 空、transition `"cut"`。
2. **单句**：narration 无标点的 beat（words 一串）→ 1 shot。

6. **显式路径**：`visual.shots = [{to: 2}, {from: 2}]`（fps=30）→ 2 shots，边界 60 帧；`words`/`motion`/`layout`/`transition` 覆盖逐字段断言（`transition: "crossfade"` 透传）。

8. **防呆**：非 kinetic kind + shots → 1 shot；`to ≤ from` 的显式条目 clamp 后仍 ≥1 帧且不越拍长。
9. **配方轮换**：枚举 `firstShotIndex ∈ 0..9`、shot 数 1..4（自造 beats），所有相邻 shot（含 `firstShotIndex` 相邻的两批之间）`motion` 互不相同；且单镜头拍 `motion === autoMotion(firstShotIndex, canBuild)`。
